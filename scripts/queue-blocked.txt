# Songs that convert fine but may not be published, with the reason.
#
# The copyright gate is the expensive part of an intake: it means finding
# the hymnal page, reading the attribution line, and often dating the
# composer. When a song fails that gate the finding is worth keeping,
# because otherwise it sits at the top of the queue at 0.0% error and the
# next pass pays the same research cost to reach the same answer.
#
# Listed songs are hidden from `list` and refused by `convert` unless you
# pass FORCE=1. They are still convertible on purpose -- the private branch
# may carry a copyrighted song; it is publishing that is barred.
#
# A song being absent from this file means nobody has checked it yet, NOT
# that it is clear. The gate still runs per song.
#
# Format:  <dash-name>  <tab>  <reason>
