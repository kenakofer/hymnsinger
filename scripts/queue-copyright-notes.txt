# Copyright findings, recorded so they are not re-derived.
#
# Establishing a song's status can take real work: finding the hymnal page,
# reading the attribution, and sometimes dating a composer from outside
# sources. That answer does not change, so it is written down here the
# first time someone works it out.
#
# These notes do NOT gate anything. A copyrighted song is a normal, expected
# outcome - the protocol publishes it to main only, and it reaches the
# private host without ever touching public-main. Being listed here means
# "the status is already known", not "skip this song".
#
# `list` shows the note next to the song, so whoever picks it up knows which
# publish path it takes before starting rather than discovering it at stage 4.
#
# A song being absent means nobody has checked it yet, NOT that it is clear.
# The gate still runs per song, and the hymnal page is the authority.
#
# Format:  <dash-name>  <tab>  <status>  <tab>  <reason>
#          status is one of: copyrighted | public-domain
